## Capability: rich-text-toolbar

### Requirement: Alineación automática de Encabezados (H1)
El sistema DEBE aplicar alineación centrada (`text-align: center`) automáticamente cada vez que se aplica el formato de Encabezado Nivel 1 (H1).

### Requirement: Justificación automática de Párrafos
El sistema DEBE aplicar alineación justificada (`text-align: justify`) automáticamente cada vez que se aplica el formato de Párrafo (ya sea seleccionándolo o por defecto).

### Requirement: Barra fija en la parte superior
El sistema DEBE mantener la barra principal anclada en la parte superior del área visible de edición al realizar scroll (`sticky top`).
